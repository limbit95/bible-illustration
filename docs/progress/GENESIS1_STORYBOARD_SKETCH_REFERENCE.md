## Purpose

이 문서는 Assistant가 제안했던 Genesis 1 전체 26-Cut 구성을 참고용으로만 보존한다.

사용자는 이 Storyboard를 그대로 제작 기준으로 사용하지 않는다.
앞으로 실제 Canonical Storyboard는 사용자가 한 장씩 직접 설계하고 프롬프트를 전달한 내용만 순차적으로 반영한다.

이 문서의 Cut 구분, beat, transition 판단, Key Scripture 후보는:

- 제작 명령이 아님
- Canonical Storyboard가 아님
- Generation Gate 입력이 아님
- 자동으로 Cut / Continuity / Presentation Plan을 생성하는 근거가 아님
