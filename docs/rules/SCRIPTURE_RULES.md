# Scripture Rules v1.0

> 상태: **CONFIRMED / 2026-10-02 사용자 승인**
>
> 목적: 성경 본문을 시각화할 때 본문 직접 내용, 역사적 재구성, 해석적 추정을 구분하고 본문에 없는 내용을 사실처럼 고정하지 않기 위한 제작 규칙을 정의한다.

## 1. 본문이 최우선이다

각 Episode와 Cut은 자신의 primary Scripture 및 Storyboard Scripture Anchor를 기준으로 제작한다.

supporting Scripture는 맥락과 병행 본문을 보조할 수 있지만 primary Scripture를 대체하지 않는다.

## 2. 본문 직접 내용과 시각적 재구성을 구분한다

다음은 본문 직접 근거로 취급한다.

- 본문에 명시된 사건
- 등장 인물
- 명시된 장소
- 실제 행동
- 실제 대사
- 본문이 제시하는 사건 순서
- 본문이 직접 설명하는 물리적 특징

다음과 같은 항목은 본문이 직접 말하지 않을 수 있다.

- 얼굴 생김새
- 머리 길이와 세부 헤어스타일
- 정확한 색상
- 배경의 세부 식생
- 특정 날씨
- 카메라 위치
- 화면 구도
- 명시되지 않은 사물의 세부 형태

이런 요소는 제작을 위한 reconstruction이며 성경적 사실처럼 설명하지 않는다.

## 3. 본문에 없는 사건을 창작하지 않는다

이야기를 더 극적으로 만들기 위한 목적으로 다음을 임의 추가하지 않는다.

- 성경에 없는 인물
- 성경에 없는 대화
- 성경에 없는 기적
- 성경에 없는 갈등
- 성경에 없는 사건
- 성경과 다른 사건 순서
- 인물의 숨겨진 동기를 사실처럼 단정하는 표현

이야기성은 창작 사건을 추가하기보다 본문 안의 시간 흐름, 장소 이동, 인물 행동, 사건 변화에서 찾는다.

## 4. 최소 구현 원칙

본문이 시각적으로 특정하기 어렵다고 해서 빈 부분을 임의의 구체적 이미지로 채우지 않는다.

다음 표현을 허용한다.

- 구체 요소가 거의 없는 화면
- 어둠 / 여백 / 추상도가 높은 분위기
- presentation layer의 텍스트 중심 연출
- 일러스트가 없는 Cut 또는 전환 장면

이 방식이 본문에 대한 과도한 해석을 줄이는 경우 적극적으로 고려한다.

## 5. 후대 장면 선행 묘사 금지

각 Cut에는 그 Scripture Anchor 시점까지 본문에서 존재하거나 형성된 요소만 표현한다.

이후 본문에서 등장·형성·이름 붙여지는 요소를 앞선 Cut에서 완성된 상태로 미리 보여주지 않는다.

이 원칙은 다음에 모두 적용한다.

- 자연 세계
- 도시와 건축
- 성막과 성전
- 왕국과 정치 구조
- 의복
- 도구
- 무기
- 인물의 생애 단계
- 사건의 결과 상태

특정 시점의 world state는 필요하면 Continuity와 Cut forbidden elements로 명시한다.

## 6. 해석을 사실처럼 고정하지 않는다

여러 해석이 가능한 본문은 우선 본문이 직접 말하는 범위까지만 시각화한다.

특히 다음은 신중하게 다룬다.

- 본문이 설명하지 않은 초자연 세계의 구체 구조
- 인물의 내면 동기
- 상징의 단일 의미
- 논쟁 가능한 신학적 해석
- 본문 밖 전승의 세부

필요한 해석적 선택은 Canonical fact와 구분한다.

## 7. 하나님 표현

본문이 명확한 육체적 현현을 묘사하지 않는 장면에서 하나님을 일반적인 인간의 몸·얼굴·손·실루엣으로 자동 형상화하지 않는다.

본문에 맞는 경우 다음과 같은 표현을 검토할 수 있다.

- 말씀 / 음성의 존재
- 빛
- 구름
- 불
- 바람
- 하늘이나 환경의 변화
- 본문에 직접 기록된 현현 방식

특정 본문이 하나님의 나타나심을 구체적으로 묘사한다면 해당 본문 자체를 기준으로 별도 검토한다.

## 8. 천사와 초자연적 존재

천사, 그룹, 스랍 등은 대중문화의 전형적 이미지를 자동 적용하지 않는다.

- 해당 본문의 직접 묘사를 먼저 확인한다.
- 외형이 설명되지 않은 경우 과도한 세부를 성경적 사실처럼 고정하지 않는다.
- 동일 존재가 반복 등장해 Library Asset이 필요한 경우 Scripture Basis와 Visual Reconstruction을 분리한다.

## 9. Cut 분할과 본문 흐름

Cut 수는 고정하지 않는다.

- 시간 변화
- 장소 변화
- 중심 인물 변화
- 사건의 종료와 시작
- 이야기 목적 변화

를 기준으로 자연스러운 장면 경계를 찾는다.

중요 사건을 지나치게 압축하지 않으며, 한 Cut에는 가능한 한 하나의 핵심 사건 또는 시각적 초점을 둔다.

## 10. Scripture Review

Generated Result 검토 시 최소한 다음을 확인한다.

- Scripture Anchor의 핵심 사건이 맞는가
- required element가 빠지지 않았는가
- forbidden / premature element가 들어오지 않았는가
- 본문에 없는 사건이나 대사가 추가되지 않았는가
- 해석적 reconstruction이 본문 직접 사실처럼 보이지 않는가

핵심 Scripture mismatch가 있으면 시각적 완성도가 높더라도 최종 대표 후보로 통과시키지 않는다.
