# Historical Rules v1.0 Working Draft

> 상태: **REVIEW READY**
>
> 목적: 성경 시대의 지역·환경·복식·건축·도구·생활상을 시각화할 때 시대착오와 근거 없는 확정을 줄이기 위한 고증 규칙을 정의한다.

## 1. 고증의 역할

역사 고증은 성경 본문을 대체하지 않는다.

본문이 직접 말하지 않는 시각적 세부를 재구성할 때 **가능한 시대·지역 범위 안에서 설득력 있게 제한하는 근거**로 사용한다.

## 2. 근거 계층

Library Architecture의 근거 계층을 따른다.

- Scripture Basis
- Historical Basis
- Visual Reconstruction
- Uncertainty

Historical Basis와 Visual Reconstruction을 섞어 기록하지 않는다.

## 3. 시대착오 방지

다음 요소가 해당 시대와 지역에 맞는지 검토한다.

- 건축과 도시 구조
- 의복과 직물
- 신발과 장신구
- 무기
- 농기구와 생활 도구
- 가구와 저장 용기
- 교통수단
- 도로와 기반 시설
- 헤어스타일과 수염
- 재료와 제작 기술

현대적이거나 후대의 익숙한 이미지를 자동으로 끌어오지 않는다.

## 4. 지역과 환경

장소가 중요한 사건에서는 실제 지리와 자연환경을 가능한 범위에서 조사한다.

검토 항목:

- 지형
- 고도
- 수계
- 기후 경향
- 식생
- 토양과 암석
- 농경 가능성
- 지역 건축 재료
- 인접 지역과 이동 관계

현재 날씨·시간대·일시적 환경 상태는 Location/Environment의 영구 정의와 구분한다.

## 5. 인물 외형

성경에 기록되지 않은 인물의 얼굴과 신체 특징은 제작 디자인이다.

다음은 역사적 맥락과 충돌하지 않는 범위에서 설계할 수 있다.

- 예상 연령대
- 체격
- 피부와 머리카락 표현
- 얼굴형
- 머리 모양
- 수염
- 일반적 의복

이런 reconstruction을 실제 역사 인물의 확정 외모라고 주장하지 않는다.

반복 등장 인물의 identity와 생애 단계는 Library Character / local profile 규칙을 따른다.

## 6. 의복

의복은 가능한 경우 다음을 구분한다.

- 시대
- 문화권
- 사회적 역할
- 직무 / 제사 역할
- 재료
- 직조와 구성 방식
- 장신구
- 색상 근거

Character와 Costume의 Source of Truth를 중복하지 않는다.

실제 장면에서 어떤 인물이 어떤 Costume을 입는지는 Cut이 소유한다.

## 7. 건축과 사물

성막, 성전, 언약궤처럼 identity가 중요한 사물은 성경 본문과 역사적 자료를 우선한다.

일반 건물·용기·등잔·가구처럼 유형적 reconstruction이 필요한 경우 시대와 지역에 맞는 형태를 사용한다.

후대에 발전한 완성 형태를 이전 시대에 소급 적용하지 않는다.

## 8. 불확실성

고고학·역사 자료가 단일 복원안을 보장하지 않는다면 하나의 시각화를 선택할 수는 있지만, 그것을 유일한 역사적 사실로 취급하지 않는다.

중요한 불확실성은 Library `uncertainties` 또는 관련 Research/Reference 기록에 남긴다.

## 9. Reference 사용

고증 Reference는 다음을 구분한다.

- 지리
- 건축
- 복식
- 사물
- 식생
- 재료
- 시대적 시각 문화

특정 고증 Reference의 색감·카메라·그래픽 스타일을 장면 전체의 Style 규칙으로 자동 승격하지 않는다.

저장 권리가 불명확한 외부 자료는 Asset으로 복제하지 않고 External Reference Record를 사용한다.

## 10. Historical Review

Result Review의 historical_accuracy를 판단할 때 최소한 다음을 확인한다.

- 명백한 시대착오가 없는가
- 장소의 핵심 환경과 충돌하지 않는가
- 건축·의복·도구가 후대 요소를 선행 묘사하지 않는가
- Scripture Basis와 Historical Basis가 서로 뒤바뀌지 않았는가
- reconstruction의 불확실성이 지나치게 사실적으로 고정되지 않았는가
